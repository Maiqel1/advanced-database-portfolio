CASE 1: Ikeja sends 300 to Ilorin, and both sites vote yes
######################################################################
Phase 1, prepare: each site does its part and promises it can commit
  Ikeja:
    BEGIN
    BEGIN
    UPDATE stock SET quantity = quantity - 300 WHERE drug = 'Amoxicillin 500 mg capsule'
    UPDATE 1
    PREPARE TRANSACTION 'transfer-1-ikeja'
    PREPARE TRANSACTION
  Ilorin:
    BEGIN
    BEGIN
    UPDATE stock SET quantity = quantity + 300 WHERE drug = 'Amoxicillin 500 mg capsule'
    UPDATE 1
    PREPARE TRANSACTION 'transfer-1-ilorin'
    PREPARE TRANSACTION
  Prepared transactions waiting for a decision:
    transfer-1-ikeja in site_ikeja
    transfer-1-ilorin in site_ilorin
Phase 2, commit: both voted yes, so the coordinator tells both to commit
    COMMIT PREPARED 'transfer-1-ikeja'
    COMMIT PREPARED
    COMMIT PREPARED 'transfer-1-ilorin'
    COMMIT PREPARED
  stock at site_ikeja: 600
  stock at site_ilorin: 340

  Ikeja cannot do its part:

  Prepared transactions waiting for a decision:

One site voted no, so the coordinator tells Ilorin to roll back its prepared part:
